# Edivino Boveto Jr.

Creative technologist from Brazil. I spent 16 years making images move (motion design, then Houdini FX on Love, Death + Robots, Superman & Lois and the feature 100 Days), then directed and animated 300+ AI shots for two vertical series. Now I build the tools I wished I had on those shows.

**[Take 9001](https://take9001.com)**: production software for studios making AI films and series. Script to shot list, boards, frames, clips, voice and lip sync, with every take pinned to its inputs, model and cost. One shot made twice, same models and references: 20 min and 318 clicks on a credits platform, 5 min and 31 clicks in Take 9001 ([video](https://youtu.be/u79w05iJNgk)).

**[Kagami](https://github.com/demoncase/kagami)**: open-source recasting app (MIT). Approve a still before paying for video, auto re-timing to the source clip, and a receipt per run with every input's hash and the price. Exports each run as a ComfyUI workflow.

Stack: Python, FastAPI, React, TypeScript, SQLite, ComfyUI, Houdini (VEX), model provider APIs. Built with Claude Code as my engineering team.
